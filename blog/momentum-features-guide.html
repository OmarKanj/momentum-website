Core Features

ONNX Model Support

Momentum natively supports ONNX format voice models, providing cross-platform compatibility and optimized performance. Simply load your .onnx model file to begin.

Audio Import

Import audio from various sources:

  • Load audio files (WAV, MP3, and other common formats)
  • Record directly within the application
  • Drag and drop for quick import

Real-Time Preview

Preview your voice conversion settings before committing to full processing, saving time and enabling rapid experimentation.

Parameter Controls

Fine-tune your voice conversion with these key parameters:

Pitch Adjustment

Control the fundamental frequency of converted voice. Measured in semitones, typical range is -12 to +12. Learn more about pitch control.

Index Rate

Controls feature retrieval strength from the model. Range 0.0 to 1.0:

  • Lower values (0.3-0.5): More original voice characteristics
  • Higher values (0.7-0.9): Stronger target voice similarity

Filter Radius

Smooths pitch changes for more natural sound. Typical range 0-7:

  • Lower values: Preserve pitch variations
  • Higher values: Smoother, more averaged pitch

Workflow Best Practices

Follow this workflow for optimal results:

  1. Start with high-quality input audio
  2. Load appropriate ONNX model for your use case
  3. Begin with default parameters
  4. Preview and adjust pitch first
  5. Fine-tune index rate for quality
  6. Adjust filter radius for smoothness
  7. Export when satisfied with results

Tips for Best Results

  • Use clean, noise-free input audio
  • Match model characteristics to your needs
  • Make small parameter adjustments
  • Test with short clips before processing long files
  • Keep multiple models organized

Troubleshooting

Poor Output Quality

Solutions:

  • Check input audio quality
  • Verify model is appropriate for your use case
  • Adjust pitch and index rate parameters
  • Try different filter radius settings

Model Won't Load

Solutions:

  • Verify file is valid ONNX format
  • Check file isn't corrupted
  • Ensure sufficient system memory
  • Update to latest Momentum version
